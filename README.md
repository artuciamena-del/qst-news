# QST عربي — موقع إخباري يعمل تلقائياً بالذكاء الاصطناعي

نظام كامل: موقع إخباري عربي متعدد الصفحات + خادم آلي يجلب الأخبار من مصادر RSS
ويكتب المقالات بالذكاء الاصطناعي **كل ساعة تلقائياً دون أي تدخل منك**، ومنشور مجاناً.

---

## مكونات المشروع

| الملف | الوظيفة |
|---|---|
| `index.html` | الموقع الكامل (رئيسية + مقال + أقسام + من نحن + اتصل بنا) — يقرأ `articles.json` |
| `fetch_news.py` | يجلب الأخبار من 5 مصادر RSS عربية، يكتب المقالات بالذكاء الاصطناعي، يولّد `articles.json` |
| `.github/workflows/daily-news.yml` | مجدول زمني مجاني على GitHub يعمل كل ساعة |
| `requirements.txt` | متطلبات Python (لا مكتبات خارجية إلزامية) |
| `articles.json` | يُولّد تلقائياً — يحوي المقالات المكتوبة بالذكاء الاصطناعي |

---

## خطوات التشغيل (10 دقائق، مجاني بالكامل)

### 1. أنشئ حساباً على GitHub (مجاني) وأنشئ مستودعاً جديداً باسم مثلاً `qst-news`

### 2. ارفع جميع ملفات هذا المجلد إلى المستودع

### 3. احصل على مفتاح ذكاء اصطناعي مجاني:
- انشئ حساباً على **Groq** (https://console.groq.com) — مجاني وسرعة فائقة
- انسخ المفتاح API
- في المستودع: `Settings → Secrets and variables → Actions → New repository secret`
  - الاسم: `OPENAI_API_KEY` ، القيمة: المفتاح الذي نسخته
  - أضف سراً ثانياً: `OPENAI_BASE_URL` = `https://api.groq.com/openai/v1`
  - وثالثاً: `OPENAI_MODEL` = `llama-3.3-70b-versatile`

> إن لم تضع مفتاحاً، سيعمل النظام بوضع تجريبي (يكتب مقالات من الملخصات دون ذكاء اصطناعي).

### 4. فعّل النشر المجاني:
- `Settings → Pages → Source: GitHub Actions`
- الموقع سينشر تلقائياً على دومين مجاني:
  **`https://اسم-حسابك.github.io/qst-news/`**

### 5. شغّل الأنبوب يدوياً أول مرة:
- `Actions → Auto News Pipeline → Run workflow`
- بعدها سيعمل **كل ساعة تلقائياً** — يجلب الأخبار، يكتب المقالات، وينشر الموقع.

## دومين مجاني / رخيص

| الخيار | التكلفة | الرابط |
|---|---|---|
| GitHub Pages (مضمن) | مجاني | `اسمك.github.io/qst-news` |
| Netlify / Cloudflare Pages | مجاني | `اسمك.netlify.app` |
| نطاق `.com` حقيقي | ~1 دولار/سنة | من Namecheap / Cloudflare |
| Duck DNS (فرعي مجاني) | مجاني | `اسمك.duckdns.org` |

> ملاحظة صادقة: النطاقات المجانية بالكامل (مثل .tk/.ml) توقفت عن العمل حالياً.
> الخيار المجاني العملي هو النطاق الفرعي من GitHub/Netlify/Cloudflare، أو شراء نطاق بـ 1 دولار سنوياً.

## كيف يعمل الذكاء الاصطناعي تلقائياً

1. كل ساعة: GitHub Actions يشغّل `fetch_news.py`
2. السكربت يزور 5 مصادر RSS عربية ويستخرج أحدث العناوين والملخصات
3. يرسل كل خبر إلى نموذج الذكاء الاصطناعي مع تعليمات: "اكتب مقالاً صحفياً عربياً من 4 فقرات"
4. يخزّن المقالات في `articles.json` ويرفعها إلى المستودع
5. GitHub Pages يعيد نشر الموقع فوراً بالمقالات الجديدة

**لا دخل لك فيه بعد الإعداد الأول.**

---

## تخصيص سريع

- **إضافة مصادر:** عدّل قائمة `FEEDS` في `fetch_news.py`
- **تغيير عدد المقالات:** عدّل `MAX_ARTICLES`
- **تغيير وتيرة التحديث:** عدّل `cron: "0 * * * *"` في ملف الـ workflow
- **تغيير النموذج:** عدّل السر `OPENAI_MODEL` (يدعم أي خدمة متوافقة مع OpenAI)
